# Task 4: Responsive Web Design

## Objective
Converted a fixed-width desktop webpage into a mobile-friendly layout using CSS media queries.

## Implementation
- Built a static, fixed-width desktop layout (1000px width) intentionally prone to mobile overflow.
- Included the viewport meta tag to ensure proper scaling on mobile devices.
- Implemented a `@media (max-width: 768px)` breakpoint to trigger the mobile layout.
- Stacked the navigation menu and main containers vertically.
- Reduced typography sizing and adjusted padding to eliminate horizontal scrolling.
- Integrated basic JavaScript for single-page DOM manipulation to handle navigation routing.
